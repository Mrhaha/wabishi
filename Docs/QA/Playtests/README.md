# 后台试玩分析工具

## 入口

在 Unity 编辑器顶部菜单打开：

`Tools / Dice King / 后台试玩分析`

窗口提供：

- `启动后台试玩（5 种策略）`：启动隔离、无窗口的 Unity 后台试玩。
- `打开本次 / 最近分析日志`：直接打开本次或最近一次生成的 Markdown 汇总。
- `打开日志目录`：定位到全部后台试玩记录。
- `打开最近一次后台 Unity 日志`：运行失败或需要检查编译、导入问题时使用。

## 默认范围

- 固定种子数量：`50`。
- 每个种子分别执行 `5` 种策略，共 `250` 局：
  - 随机基线。
  - 眼前得分。
  - 长期成长。
  - 经济利息。
  - 路线构筑；按种子轮换深壳、广壳、法术壳和驻场龟群。
- 自动玩家调用真实投点、`ScoreDice`、市场购买 / 卖出 / 刷新、法术、离场队列和生命续投逻辑。
- 为提高批量效率，只跳过投骰、结算、失败扫描与离场的纯表现等待，不跳过真实规则执行。
- 后台运行设置 `suppressSave = true`，不会写入或清除正式 `PlayerPrefs` 运行存档。

## 无窗口运行

主编辑器只负责同步一个最小隔离工程并启动后台进程。隔离工程位于系统临时目录：

`WabishDiceKingPlaytestWorker`

后台 Unity 使用：

`-batchmode -nographics`

因此不会切换当前 Unity 场景、进入当前编辑器的 Play Mode，也不会弹出游戏或控制台窗口。后台进程仍会出现在系统任务管理器中，并会产生正常的 CPU、磁盘和日志活动；本工具不用于规避设备管理或审计。

## 日志命名

日志目录：

`Docs/QA/Playtests/yyyyMMdd/`

文件前缀使用启动试玩的本地时间：

`yyyyMMdd_HHmmss`

若同一秒已经存在同名前缀，则依次使用：

`yyyyMMdd_HHmmss_2`、`yyyyMMdd_HHmmss_3`……

每次运行生成：

- `*_playtest_summary.md`：策略对照、自动诊断与结论边界。
- `*_playtest_decisions.jsonl`：每一步状态、候选、选择、可审计理由与实际结果。
- `*_playtest_runs.csv`：每局通关、关卡、投掷、市场、买卖、法术、生命和错误汇总。
- `*_playtest_chain.log`：真实 `[CHAIN]` 规则执行日志及错误。
- `*_unity.log`：后台 Unity 导入、编译和运行日志。
- `*_status.txt`：供编辑器窗口读取的简短进度。

## 分析边界

后台样本用于发现：

- 规则错误、状态停滞和连锁上限。
- 不同策略的通关率、到达关卡和耗命差异。
- 购买、卖出、刷新、施法与构筑是否形成可测收益。
- 经济断层、长期成长不足、绝对优势路线和无效选择。

无窗口样本不能替代动画、声音、鼠标手感、文字可读性和主观爽感验收。表现层仍需离屏截图或真人 Play Mode 体验。
