## 首轮实玩反馈修正

- 用户首次进入 Play Mode 时发现：`DiceKingDemo: tooltip for LeaderTurtle uses keyword 'shell' without a die binding.`
- 原因是初次静态合同错误地把 Tooltip 释义绑定数量当作吸附形态数量，删除了首领龟的 `shell` 绑定。
- 已恢复首领龟绑定，并新增“Tooltip 中每个 `{{kw:...}}` 都必须同时存在词典定义与对应骰子绑定”的全量静态检查。
- 该绑定只控制 Tooltip 释义；首领龟的驻场形态仍由代码分类决定。当前静态回归通过，待用户重新进入 Play Mode 确认控制台不再报错。
- 市场名称与规则正文中的 `?` 来自 V4 LED map 缺少 F023 新增的 25 个汉字。已重跑同源生成器，字形数从 911 增至 936；二十龟可见字符和全局源字符均为 0 缺字。
- 描述异常另有独立布局根因：“化壳”解释在 400 px Micro 点阵正文宽度下实际为 3 行，旧的 36 单位估算只分配 2 行。现改为 23 单位、最多 6 行，静态像素测量已确认不裁切。
