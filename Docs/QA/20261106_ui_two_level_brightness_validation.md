# 页面风格与两档文字亮度验证

日期：2026-11-06

状态：请求中的主游戏页面与法术袋已完成修改、独立编译、同源门禁和双分辨率运行截图检查；市场入口最后一处材质路由修正已编译，最新运行截图仍待编辑器重载后补验。最终观感待用户实机确认。

## 用户要求与原因

用户要求页面风格统一，常驻内容不要出现不必要的忽亮忽暗，文字仅保留普通与必要高亮两档。反馈截图分别为右侧规则终端和主游戏法术袋入口。

- 规则标题使用 `PrimaryAmber`，正文使用更暗的 `SecondaryWarm`，形成常驻亮度差。
- 法术袋入口调用旧 `DrawUiButton`，产生奶油色整块背景、双色装饰与皇冠，与暗色机台不一致。
- 法术面板继续复用羊皮纸底板和多种棕色墨字，展开后风格再次切换。
- 审查共用界面时发现法术静态价格与闲置刷新键误用焦点亮度；运行截图另暴露市场法术袋入口误用浅色实体键帽的深墨字。

## 修改

- `main_game_led_text_roles.csv` 与 `main_game_led_text_brightness_groups.csv` 同步维护普通 `Normal` 与高亮 `Highlight`。所有普通发光角色的硬核心统一为 `#FFC04A`、不透明，目标感知亮度为 `0.845166`；焦点与必要结果提示保持等亮的高亮核心，目标为 `0.884625`。
- 保留原有角色名称与三档整数点阵几何。旧 L0 / L1 / L2 / L3 不再代表额外亮暗等级；实体骰面与已批准的市场实体键帽保留材质例外。
- 主游戏法术袋入口改为 `DrawArcadeDisplayButton`，待机普通亮度、悬停高亮，不再出现奶油亮块和皇冠。
- 法术面板、卡片与选择步骤统一暗底；通过 `MainGameLedFont.RoleColor` 从共享合同取得普通文字色。可执行的施放 / 选择按钮使用高亮，受阻按钮保持普通文字和原因文案，点击资格不变。
- 法术静态价格、闲置刷新键回到普通档，法术卡常驻边框改为低对比结构线。
- 市场“打开法术袋”使用暗面板 LED 路由，修正深墨字落在暗底上几乎不可见的问题。
- 同步 `PROJECT_CONTEXT.md`、`GAME_FLOW.md` 与 `Docs/UI_ACCEPTANCE_FEEDBACK_WORKFLOW.md`。

本轮不改布局位置、施法窗口、计分、交易、随机、配表数值或存档格式。工作区原有未提交修改继续保留。
