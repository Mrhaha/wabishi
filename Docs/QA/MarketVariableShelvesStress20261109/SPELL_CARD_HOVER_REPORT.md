## 当前展示

用户已确认覆盖旧常驻全文方案：卡面常态显示插画、名称、实际价格与购买键，完整效果只在悬停详情中出现。详情读取完整 `RuleText`，不改写或省略条件。

离线原型以每页四张、单卡 `240×224` 作为本轮候选。第七十七轮按用户反馈将价格与购买键改为上下居中排列：插画安全区调整为 `216×92`，价格在上、购买键在下，二者统一宽 `216`，竖向间距为 `6`。该容量通过本轮离线检查，仍不是正式商品数上限或已接入的 Unity 布局。

## 悬停实现

- 鼠标进入卡面约 `120ms` 后显示详情，相邻详情替换延迟约 `60ms`。
- 卡画、名称、价格与购买区域共用同一个悬停目标；在卡内移动不会反复关闭重开。
- 详情为独立层，只重绘该层，不重建当前卡面的鼠标或焦点元素，避免悬停定时器触发重绘后抖动。
- 详情宽 `496`，正文宽 `464`，高度按全文计算；横向夹入安全区，底边不低于逻辑坐标 `268`，避开上排购买键及底部主操作。
- 详情不接收鼠标，不截获购买。翻页、重建批次、购买、换货变类、离场锁定或切换分辨率会取消待显示任务并清理旧详情。
- 原型额外提供键盘聚焦同详情及 `Esc` 关闭，作为可访问性验证候选；不将其擅自升级为已确认的正式输入方案。

## 验证结果

- 原生 `1280×720 / 1920×1080`，骰子数与法术数分别取零、一、二、三、四、六、八、十二、三十二，共一百六十二组交叉数量组合。
- 共八百八十二次含重复首屏的状态检查与十二项数量／交易原型交互检查，装入与索引失败为零。
- 三十二项悬停检查通过，浏览器错误为零：八张开放法术全文、左右端与末页详情安全框、所有购买键不被遮挡、卡内移动稳定、悬停不替换主界面节点、购买后清理、待显示期间切页／重建／购买／离场／分辨率切换／变类均不复活旧详情。
- 通过键盘聚焦、`Esc`、失焦的原型可访问性检查。
- 常态绘制列表没有法术 `RuleText`；仅卡面悬停后的独立详情含完整规则。
- 两个本地文件入口、四／六／八／三十二件数量即时切换、独立分页与双分辨率点击再次通过入口回归。

当前四张／页下，四／六／八／三十二张法术分别为一／两／两／八页。旧每页两张的结论只适用于常驻全文方案，不再限制本轮图文卡。
