# F023 界面体验规格

状态：静态接入，待 Play Mode
功能：二十龟四路线玩法验证
关联界面文档：`PROJECT_CONTEXT.md`、`GAME_FLOW.md`

## 输入决策

- 三格总货架每批展示 `1–2` 个 F022 法术商品；其余骰子位仅展示二十枚龟龟相关骰。
- 复用现有市场、拖拽排序、悬浮页、离场动画和结算短标签。
- 法术购买统一使用 F022 三格混合货架，施放使用独立法术袋与目标选择面板。

## 体验意图

玩家无需阅读日志即可知道骰子是驻场还是吸附、正式法术当前价格与法术袋占用、宿主有哪些壳、下一次结算是否已有法术充能。

## 界面 / 状态

| 状态 | 玩家目标 | 可见信息 | 主操作 | 次操作 | 退出 / 下一状态 |
|---|---|---|---|---|---|
| 混合龟龟市场 | 买入、卖出、排序 | 三格混合商品、价格、袋容量、离场预览 | 购买骰子或法术 | 刷新 / 卖出 / 排序 | 离开市场 |
| 法术商品格 | 购买法术并发布购买事件 | 法术身份、卡名、价格、学徒折扣、法术袋占用 | 购买法术 | 刷新 / 继续市场 | 法术袋 |
| 正式法术袋 | 施放法术并发布根施放事件 | 持有牌、可用阶段、目标与阻塞原因 | 选择并施放 | 取消 / 继续市场 | 市场或投骰前 |
| 离场队列 | 观察真实吸附 | 来源、目标、高亮、短结果 | 无 | 无 | 离场后生成 |
| 悬浮页 | 理解骰子与壳状态 | 家族、触发、规则、六面、壳摘要、充能 | 悬浮查看 | 无 | 返回当前界面 |

## 信息层级

- L2：骰子名、价格、法术牌名、法术袋占用和实际费用。
- L1：驻场 / 吸附规则、壳摘要、待消费折扣和充能。
- L0：重复壳的折叠明细和日志。

## 交互流程

1. 玩家从三格混合货架购买龟龟并在六槽内排序。
2. 市场内可从其中的法术商品格购买法术；购买先应用学徒折扣，再发布购买事件。
3. 玩家从独立法术袋选择法术并完成目标选择；施放消耗一张并发布一次根法术事件。
4. 离开市场后按左到右执行真实吸附；全部吸附完成后再执行离家出走龟生成。
5. 新生成的领路龟不进入本次吸附扫描。

## 反馈和动画

- 正式法术购买和施放复用统一短时提示。
- 吸附继续使用来源飞向后一位宿主和宿主高亮。
- 同一局部链最多完整显示二到三步；重复层在短标签和悬浮页汇总。

## 边界情况

- 骰袋满时离家出走龟不生成。
- 法术袋达到配置容量（默认 3）时购买键受阻；空袋时没有可施放卡牌。
- 金币不足时显示实际折后价格。
- 法术系统关闭时三个货架全部回到骰子商品，不显示法术袋入口。
- 新骰缺少专属图标时显示龟龟回退图标。

## 适配 / 布局约束

- 不改变市场三个总货架和六格骰袋结构。
- 法术商品复用现有货架卡面，法术袋使用 F022 共享面板，保持离开和刷新主键不变。
- 长规则继续使用现有悬浮页折行和最大高度。

## 实现备注

F023 不拥有卡牌规则，只监听 F022 发布的正式购买与根施放事件；复制施放不得再次计为根施放。

## 阻塞项

无。

## 验收

- 鼠标可完成正式法术购买、选牌、目标选择、取消与施放。
- 实际价格、折扣、持有数和阻塞原因一致。
- 新增骰悬浮页不为空，双阵营标签正确。
- 未运行 Unity Play Mode 前只可标记静态接入，不可称界面验收通过。
