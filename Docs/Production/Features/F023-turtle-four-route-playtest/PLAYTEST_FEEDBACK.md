### 需要修改的结论

- `keyword_binding_config.csv` 的绑定用于 Tooltip 释义覆盖，不能直接当作“会吸附的骰子数量”。
- 吸附形态由 `IsF018AbsorbableTurtleType()` 判断；首领龟恢复 `shell` 绑定后仍是驻场龟。
- 新增运行时中文文案后必须重跑 `build_main_game_led_font_atlas.py`；当前字库由 `911` 扩至 `936` 个字形，新增缺字 `25` 个、修复后缺字 `0`。
- Tooltip 关键词说明使用 Micro 点阵字体；400 px 正文宽度约容纳 23 个全角字，不能继续按 36 个全角字估高。
