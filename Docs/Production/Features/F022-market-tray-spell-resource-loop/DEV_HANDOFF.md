## 阶段合同

```text
市场：
  mode == InterStageMarket || mode == ChapterShop
  && !marketLeaveEffectSequenceActive

投掷前：
  mode == Run
  && rollPhase == Ready

其它状态：
  全部不可施法
```

- `BeginShakeRoll()` 必须关闭面板并取消尚未提交的目标。
- 目标选择只属于准备态；点击取消、`Esc` 或阶段切换不得消耗牌。
- 施放提交后先移除法术，再结算牌效和一次正式 `SpellCast` 根事件，最后保存。
- 购买提交后扣费、消耗下一法术折扣、加入袋、清空货位，发布一次正式 `SpellPurchased` 根事件并保存。

## 三格混合市场货架

- `EnterMarket()` 与每次 `BuildMarketOffers(true)` 都重建同一组三个总货架。
- 每批先按配置确定法术格数：`clamp(spell_market_min_shelves, 0, 3)` 为保证值，最多不超过 `spell_market_max_shelves`；首轮仅用 `spell_market_extra_shelf_chance` 判定是否从 `1` 格升级到 `2` 格。
- 法术商品直接写入 `marketOffers`，使用自己的三段章节权重；同批存在多个合法候选时尽量避免同名。
- 剩余位置才生成骰子或深渊贡品。F023 等专项骰池只过滤这些骰子位，不移除法术商品。
- 法术不满足、重置或推进高阶骰保底。若本批没有普通骰子位，高阶保底继续保留到后续刷新。
- 买走后该货架为空，只有付费整刷或重新进店补牌。
- 法术袋满、金币不足、货架为空或市场离场锁定时购买失败且不改状态；袋满不阻塞同批骰子购买。
- F023 的 `nextSpellPurchaseDiscount` 在一次正式法术购买时全部消耗，实际价格最低为 `0`。
- 只处理骰子商品的黑帆、魔蝠、抢劫与供给类逻辑忽略法术；读取空货架的逻辑仍把买走法术后的空位视为普通空位。

## 八张首片法术

### 冲关增幅

- 施放：`pendingSpellScoreBonus += 5`。
- 计分：骰子、连锁、倍率和现有额外分完成后，于达标判定前加入本次新增分。
- 多张叠加；结算后清零。

### 连锁分红

- 施放：`pendingSpellDividendCardCount++`。
- 计分结束后统计 `TypeTriggeredThisSettle == true` 的不同实体骰，单张收益 `min(4, count)`。
- 每张牌分别产生一笔合并金币事件；复制不会新增实体计数。
- 结算后清零。

### 回声指令

- 施放时选择骰袋实体并保存稳定骰 ID；允许同目标叠加。
- 当目标下一次首次发布可复制、非复制的家族本体根效果时，每张绑定额外执行一次。
- 复制执行通过既有 `CopiedEventDepth` 关闭所有复制入口。
- 目标未触发、被卖出或不存在时，结算后直接清除。

### 定向换货

- 只在市场使用。
- 先选四个主体家族之一，再选任意非空市场货架；目标可以是骰子或法术商品。
- 从当前章节、当前测试池 / 正式池、该家族合法候选中按现行权重随机生成，排除基础骰与贡品。
- 使用现行市场最低点和锁价公式。
- 不算付费刷新或采购，不推进刷新价、高阶保底或黑帆。

### 精密校准

- 选择骰袋实体，六个长期面各 `+1` 后排序。
- 不改已经发生的投掷；阶段门保证只能在投前执行。

### 饲料袋

- 选择骰袋实体，连续调用两次现行真实喂养入口，每次 `1` 份当前品质。
- 肉猪与贪吃猪分别按现行规则响应。
- 本切片没有交易托盘目标。

### 削峰套现

- 只在市场使用。
- 对每颗骰子先记录各自最高长期面，再把所有等于该快照最高值的面减 `1` 并排序。
- 每颗成功处理的骰子计 `1` 金，整张牌只调用一次金币入账。

### 超额悬赏

- 施放：`pendingSpellBountyCardCount++`。
- 下一次结算以 `rollScore` 比较 `CurrentEncounter().Target * 3`；`rollScore` 含冲关增幅，不含 `currentScore` 的旧累计分。
- 每张成功牌获得 `8` 金并形成一笔金币事件；失败无收益。
- 结算后清零。
