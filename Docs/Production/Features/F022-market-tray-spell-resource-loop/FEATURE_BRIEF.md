## 一句话目标

2026-11-09 用户批准实施后，F021 第七十四至七十七轮确认的商店界面已接入 Unity：上排骰子、下排图文法术、分类每页四件、悬停完整效果，以及价格在上和购买键在下。两档原生分辨率、七十二组数量组合与受控 GUI 提交已通过，具体证据见 `Docs/QA/MarketVariableShelvesUnity20261109/REPORT.md`。本次只变更表现与目标展示映射；每批三个真实商品的生成规则、经济、牌效与 `SaveVersion = 14` 保持。三张插画示意已进入运行原型，其余法术暂复用，完整正式插画包不在本次范围。

让法术成为一次性连接计分、家族效果、长期面组、喂养、市场供给和金币的公共工具，同时保持“投掷前做决定，投掷后直接结算”的主流程。

## 玩家体验

- 玩家在市场决定买哪张法术、立即使用还是占用有限法术袋保存。
- 法术与骰子共用三个真实货架；玩家能直接看见本批 `1–2` 个法术选择及其占用的市场机会。
- 离开市场后，玩家可以在投掷前完成最后一次施法与排序。
- 投掷开始即锁定所有法术输入；结果出现后不再补救，只观看自动结算。
- 法术提供短期转向和跨家族接口，不替代骰子本身的长期构筑。

## 已确认的系统规则

- 法术袋独立于骰袋，容量由 `global.csv` 配置，首版为 `3` 张。
- 普通市场与章节市场都只有 `3` 个总货架。进入市场和付费整刷时，其中至少 `1` 格、至多 `2` 格生成法术，其余生成骰子。
- 法术货架数量由 `global.csv` 的最少格、最多格和第二格概率控制；首轮灰盒值为 `1 / 2 / 35%`。具体牌种继续读取 `spell_market_config.csv` 的章节权重，同批尽量不重复。
- 法术真实占用货架，买走后该格留空，只有下次整体刷新补货。法术位不满足、重置或推进骰子高阶保底。
- 法术购买后进入法术袋，可跨市场、关卡和生命续投保存；施放后消耗。
- 首片法术袋已满时不能购买，不提供免费丢弃或自动替换。替换规则后置到专门的法术袋压力测试。
- 施法阶段只有：
  - `市场`：市场开放且离场队列尚未锁定时。
  - `投掷前`：`Run + Ready`，包含正常离店后的首次投掷前与生命续投后的再次投掷前。
- 同一阶段可连续施放多张；一张法术及其响应完整结束后才允许下一张。
- 投掷开始时关闭法术面板和目标选择。`Shaking / Stopping / ResultDecision / Scoring` 均不能施法。
- “下一次结算”只绑定下一次完整结算；无论达标、失败、条件未触发或目标失效，结算后都清除。

| 2 | 连锁分红 | `2` | 市场 / 投掷前 | 下一次结算中，每有一颗不同的骰子触发自身效果，结算后获得 `1` 金币，最多 `4` 金币。 |

| 4 | 定向换货 | `3` | 市场 | 选择 `1` 个家族和 `1` 个非空货架位，将该商品替换为当前章节该家族的随机骰子。新商品仍需正常购买。 |

| 8 | 拆解许可 | `4` | 市场 | 销毁交易托盘中的 `1` 颗骰子且不获得卖价；选择另一颗骰子，按普通规则吞吃该材料。 |

## 统一事件边界

- `连锁分红`：每颗实体骰最多计数一次；复制执行与法术本身不增加计数；每张牌的收益合并为一笔真实金币事件。
- `回声指令`：只复制可复制的本体根效果；复制执行不再打开回声、二重唱、伟大龟或其它复制入口。目标未触发时照常消耗。
- `定向换货`：只选择猪猪、恶魔、龟龟或海盗；不算付费刷新或采购，不推进刷新涨价与高阶保底。
- `饲料袋`：两次喂养按顺序分别发布真实喂养事件。
- `削峰套现`：逐骰读取施法前快照，所有并列最高面都减 `1`；每颗骰子只计一份金币，整张牌合并入账。
- `拆解许可`：沿用现有吞吃转移值、来源与恶魔监听，不另造半值公式。
- `换班凭证`：原子交换；新骰首次装入旧槽，旧骰成为回收骰。回收不是采购或出售，归位不重放首次装入。
- `超额悬赏`：只读取下一次结算新增分；同次冲关增幅计入，本关旧累计分不计入。

## 开放顺序

- 首次基础池：冲关增幅、连锁分红、定向换货、精密校准。
- 第 `3` 章起加入：回声指令、饲料袋、削峰套现、超额悬赏。
- 交易托盘接入后加入：拆解许可、换班凭证。

章节只是当前灰盒的可配置代理；未来若有正式教学解锁，再把开放条件迁移到教学状态。

## 分片范围

### 第一可玩切片

- 三格混合市场货架：每批 `1–2` 格法术，其余为骰子；以及独立三格法术袋。
- 市场 / 投掷前两个入口。
- 前七张与超额悬赏，共八张可生成、购买、保存、施放和结算。
- 法术购买 / 施放继续驱动 F023 法术龟的正式根事件。
- 法术袋、待结算绑定与回声目标进入存档。
- 程序灰盒面板与目标选择；不生产新美术。

### 后续交易托盘切片

- 两格交易托盘与采购 / 首次装入分离。
- 拆解许可与换班凭证。
- 托盘清盘、来源、回收与首次装入防重放。

## 成功定义

- 玩家只能在市场和投掷前施法，投掷后无入口。
- 法术购买、持有、施放、目标和下一次结算绑定都能被看懂并稳定保存。
- 八张首片法术都至少存在一个合理使用状态与一个合理跳过状态。
- 市场始终保持三个总货架；法术位不满足或重置骰子高阶保底，生命累计续投与自动结算流程不变。
- 法术货架在最低 `1280×720` 布局中显示完整牌效，正文多行换行且不使用省略号隐藏规则。
- 两张托盘牌在托盘切片完成前不会被随机生成。
