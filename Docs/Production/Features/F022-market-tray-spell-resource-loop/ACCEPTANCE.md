## A. 阶段与容量

- [x] `spell_bag_capacity` 默认读取为 `3`。
- [x] 市场与 `Run + Ready` 可以打开法术袋。
- [x] 投掷开始后法术面板关闭。
- [x] `Shaking / Stopping / ResultDecision / Scoring` 没有施法入口。
- [x] 生命续投回到 `Ready` 后重新允许投掷前施法。
- [x] 同一阶段可以连续施放多张，每张独立结清。
- [x] 法术袋满时购买不扣钱、不清货位、不触发购买事件。

## B. 货位与购买

- [x] 每次进入市场和付费整刷后总货架数仍为 `3`。
- [x] 每批法术货架数始终落在配置的 `1–2` 格范围内。
- [x] 默认第二个法术货架按 `35%` 配置概率生成。
- [x] 法术按当前章节权重生成，同批有其它合法候选时尽量不重复。
- [x] 法术真实占用三格中的一个货架；买走后该格保持为空。
- [x] 法术不满足、重置或推进骰子高阶保底；没有普通骰子位时保底延续。
- [x] 购买消耗下一次法术折扣，实际价格最低为 `0`。
- [x] 抄经龟只读取成功的正式法术购买。
- [x] 法术袋满只阻塞法术购买，不阻塞同批骰子购买。
- [x] 新法术卡常态为插画、名称、价格与购买键；完整 `RuleText` 仅在悬停详情中显示，沿用 LED 多行排版且不截短。
- [x] 当前八张牌在 `1280×720 / 1920×1080` 的悬停几何与原生截图检查中完整装入，不被屏幕边缘或购买键裁切。

## C. 施放与目标

- [x] 无目标牌点击后提交、消耗并保存。
- [x] 有目标牌取消、`Esc`、目标失效或阶段变化时不消耗。
- [x] 成功施放只发布一次根法术事件。
- [x] 咒壳龟和大法术龟读取正式根施放，响应不递归发布法术。
- [x] 存档恢复后法术袋顺序、重复牌与待结算绑定不丢失。

## D. 八张首片法术

### 冲关增幅

- [x] 单张为下一次新增分 `+5`，多张可叠加。
- [x] 在达标判定和超额悬赏比较前计入。
- [x] 结算后清零，不跨生命续投。

### 连锁分红

- [x] 每颗不同实体骰最多计一次，单张最多 `4` 金。
- [x] 复制执行与法术事件不增加计数。
- [x] 每张牌只产生一笔合并金币事件。
- [x] 条件为零时仍清除绑定。

### 回声指令

- [x] 目标下一次首次可复制本体根效果额外执行一次。
- [x] 同目标多张可分别执行一次。
- [x] 复制不再打开回声、二重唱、伟大龟或触发器入口。
- [x] 目标无合法效果、被卖出或不存在时结算后清除。

### 定向换货

- [x] 只在市场使用。
- [x] 选择四个主体家族之一与非空货架。
- [x] 新骰符合当前章节、当前池和所选家族。
- [x] 不出现基础骰或贡品。
- [x] 不增加付费刷新次数、刷新价或高阶保底计数。
- [x] 新商品仍需正常购买。

### 精密校准

- [x] 目标六个长期面各 `+1` 并保持排序。
- [x] 不产生额外投掷或临时点数。

### 饲料袋

- [x] 对同一骰子顺序执行两次真实喂养。
- [x] 肉猪和贪吃猪按现行规则响应。
- [x] 首片只允许骰袋目标。

### 削峰套现

- [x] 每颗骰子的所有并列最高长期面都减 `1`。
- [x] 以施法前逐骰快照判断。
- [x] 每颗骰子最多提供 `1` 金。
- [x] 整张牌只发布一笔金币事件。

### 超额悬赏

- [x] 只比较下一次新增分与本关目标 `3` 倍。
- [x] 冲关增幅计入，旧累计分不计入。
- [x] 单张成功 `+8` 金，失败无收益。
- [x] 无论成功失败都在该次结算后清除。
