# F022 界面体验规格

状态：2026-11-09 分类图文卡、悬停详情与价格纵排已接入 Unity，自动验证通过；物理鼠标连续操作及最终观感待实机回归
设计分辨率：`1280×720`，同时检查 `1920×1080`
视觉基线：F021 旧机厅主游戏与市场

## 2026-11-09 展示约束变更

用户已明确要求法术卡表现为卡面插画与必要文字，完整法术效果仅在鼠标悬停时显示。本决定覆盖本包旧“卡面常驻完整 `RuleText`、不可依赖悬浮详情”的要求，当前运行时已经接入。市场改为左侧自有骰袋、上排骰子与下排法术，各类每页四件，价格居中在上、购买键在下。供给数量、法术袋容量、施法阶段、牌效和购买规则保持；三张插画示意暂供复用，不等于完整正式美术已完成。

## 体验目标

2026-11-09 补充确认：骰子与法术商品的价格和购买键统一纵排，价格居中在上、购买键在下，共用竖向中线；不再横向并排。该排版现已接入 Unity，并通过原生双分辨率的逻辑矩形与截图检查。

玩家随时能回答：

1. 法术袋里有哪几张牌。
2. 当前是否处于可施法阶段。
3. 施放后影响现在、下一次结算还是市场供给。
4. 目标为何合法或受阻。
5. 投掷开始后为何不能继续施法。

## 常驻入口

### 市场

- 当前运行规则以三个市场货架统一承载骰子或法术，每批生成 `1–2` 张法术；该现状不构成分类展示区的永久容量上限。
- 法术货架使用图文卡面，常态显示法术身份、卡面插画、名称、实际价格和购买键，视觉上不得伪装成骰子，也不再以纯文字规则块为主体。
- 鼠标悬停时才展开完整效果详情，读取未经删减的 `RuleText` 并多行排版；不允许截短、裁切或用省略号代替完整牌效。名称与价格继续按既有发光文字合同显示，购买键继续沿用实体键帽文字合同。
- `1280×720 / 1920×1080` 的图文卡与悬停详情自动检查已通过；定向换货作为完整效果最长压力文案。长正文空间由详情区域承接，不通过删改真实规则适应卡面插画。第七十五轮法术两张每页仅保留为旧常驻全文方案的历史结论，当前图文卡采用每页四张并保留分类分页。
- 底部中央只显示“法术袋 `n/容量`”入口与混合货架提示，不提供独立法术购买键。
- 任一商品买走后该货架显示为空；只有整体刷新补充。
- 离场队列锁定后，购买与法术袋入口统一禁用。

### 投掷前

- `Run + Ready` 的主操作键之外显示“法术 `n/容量`”入口。
- 没有法术时仍可显示禁用入口，帮助玩家识别系统位置。
- `Space` 开始投掷时面板立即关闭。

### 投掷后

- `Shaking / Stopping / ResultDecision / Scoring` 不显示法术入口。
- 结果锁定终端继续显示“自动进入结算”，不出现灰色残留法术按钮。

## 共用法术面板

- 面板覆盖在当前场景之上，不切换游戏状态。
- 顶部显示阶段：`市场` 或 `投掷前`。
- 当前法术袋容量首版为三张；共用法术卡现已接入卡面插画、名称、可用状态和“施放”的常态展示，完整效果仅在鼠标悬停详情中出现。原施放、目标与取消入口保留；物理鼠标连续施放与取消仍待用户实机回归。
- 右上固定显示“关闭”；`Esc` 等价取消。
- 非法牌保留可读文本，按钮禁用并显示短原因。
- 点击无目标牌后直接提交。
- 点击有目标牌后进入同一面板的目标步骤；取消返回法术列表，不消耗牌。

## 目标流程

| 法术 | 流程 |
|---|---|
| 回声指令 | 选择一颗骰袋实体；无可复制本体效果的骰仍允许选择，风险由玩家承担 |
| 定向换货 | 先选猪猪 / 恶魔 / 龟龟 / 海盗，再选一个非空且有合法候选的货架 |
| 精密校准 | 选择一颗骰袋实体 |
| 饲料袋 | 首片选择一颗骰袋实体；交易托盘接入后再增加托盘目标 |
| 其它首片法术 | 无目标，点击后提交 |

目标按钮使用骰子短名和当前面组。定向换货的家族和货架必须在提交前同时可见。

## 反馈

- 购买：`已购买「法术名」`。
- 袋满：`法术袋已满`。
- 阶段错误：`只能在市场使用` 或 `投掷已经开始`。
- 下一次结算绑定：`已绑定下一次结算`。
- 永久成长：显示目标名与面组变化。
- 削峰套现：显示处理骰数与合并金币。
- 目标失效：保持法术，不提交。
- 投掷开始：只关闭面板，不额外弹出警告。

成功与受阻反馈继续使用 F021 的 `UpperCenter` 单槽提示。

## 信息层级

- L3：当前唯一提交按钮。
- L2：法术名、价格、阶段、目标。
- L1：完整规则、袋容量、待结算绑定摘要。
- Disabled：阶段错误、无目标、袋满、货架空或离场锁定。

同一时刻只有一个 L3。法术面板打开时，底层市场与投掷按钮不处理点击。

## 适配

- `1280×720` 下当前容量的法术卡面、合法目标与关闭按钮必须可读；完整规则在悬停详情中展开，不要求全部卡牌同时常驻规则正文。
- 规则优先换行，不把关键名称缩到 Micro。
- 市场货架卡的插画、名称、实际价格与购买键必须同时装入；完整基础牌效仅由悬停详情承接，不再受旧常驻正文约束。详情需在画面安全区内自动避边，不裁切牌效、不遮挡当前购买键，也不改变商品原索引或交易资格。
- 面板不得遮挡 `UpperCenter` 提示的最终停留区。
- `1920×1080` 使用同一虚拟布局，不另建第二套交互。

## 首片验收

- 市场能购买并立即施放，也能保存到下一关。
- 投掷前能连续施放多张。
- 开始投掷后入口与面板同时消失。
- 目标取消不消耗法术。
- 法术袋三格满时，法术购买不扣钱、不清空货架；同批骰子购买不受影响。
- 每次进店或整刷都能在三个货架中直接辨认 `1–2` 张法术；不会在底部出现第四个购买位。
- 法术购买与施放有不同反馈。
- 现有市场购买、刷新、卖出、排序与离场仍可用。

## 后续托盘切片

托盘接入后再补：

- 两格托盘常驻区域。
- 拆解许可的“材料 → 目标”流程。
- 换班凭证的“新骰 → 旧骰 → 原子预览”流程。
- 托盘未清时的离场阻塞与回收标记。

首片不得用临时弹窗伪造不存在的托盘。
