## 已接入修正

- 新增 `spell_market_min_shelves / spell_market_max_shelves / spell_market_extra_shelf_chance`，默认 `1 / 2 / 35`。
- 法术成为 `MarketOfferKind.Spell`，与骰子商品共用三个货架和同一购买入口。
- 具体卡牌继续读取章节权重，同批有多个合法候选时尽量不重复。
- 买走法术后该格变空；付费整体刷新或重新进店才补货。
- 法术不满足或重置骰子高阶保底；骰子专属市场效果忽略法术商品。
- 法术袋满只阻塞法术购买，不阻塞同批骰子购买。
- 底部独立购买位删除，只保留法术袋入口。
- 法术卡从 `155` 虚拟像素窄卡扩为 `229` 虚拟像素宽卡，名称继续使用 L2 语义角色。
- 正文不再调用 `TooltipTrim`，直接显示完整 `RuleText` 并使用多行 LED 排版。
- 八张首片正文均在 `201×86` 正文框内装入，冲关增幅为 `2` 行，最长的定向换货为 `4` 行。
