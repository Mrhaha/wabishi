# F024 骰池精简 · 三十颗骰子

状态为程序已实现，人工试玩待验收。来源为 2026-11-23 用户给出的五组骰子与效果。当前可玩版本使用新版 30 骰商店。下方决策与切片表保留方案形成时的记录，实际接入的首测口径、运行验证和未验项见 [运行记录](../../../QA/20261123_f024_runtime.md)。

## 玩家拿到一颗骰子时要懂什么

| 组别 | 玩家要做的决定 | 六颗正式骰子 |
|---|---|---|
| 猪 | 把饲料喂给谁，何时卖猪改善下一次喂养 | 喂养者、肉猪、转移猪、母猪、贪吃猪、批发商 |
| 龟 | 离店前选好宿主，权衡持续收益与宿主卖价 | 金钱龟、小小龟、倍数龟、首领龟、领队龟、基础龟 |
| 恶魔 | 进店强化货架，决定哪些骰买走、哪些留给恶魔吃 | 小鬼骰子、蝠魔骰子、吸血骰子、深渊骰子、吞噬骰子、始祖魔骰子 |
| 海盗 | 调整刷新、买卖与钱包节奏，用站位换取点数和金币 | 哨兵海盗、抢劫海盗、财宝海盗、海贼王、海盗头领、人口海盗 |
| 中立 | 用有限的骰袋位置放大投出、结算、回合或商店的某一段 | 光牙骰子、王冠骰子、附魔师骰子、税务骰子、回溯骰子、二重唱骰子 |

逐颗效果、旧类型标识、废弃清单与开局骰及祭品的定位见 [名册](ROSTER.md)。中立占六个设计名额，沿用项目的四主体家族计数。旧双阵营九种全部废弃。

## 需要拍板的玩法口径

下表是给首轮试玩的建议值。原文里已经明确的目标、次数和数值见名册，以下提案须在对应切片接入前定案。

| 项目 | 首轮建议 | 用一个局面判断是否符合预期 |
|---|---|---|
| 开始、结算和结束的重触发 | 一手一回合，失败续投也算新回合（D9）。建议开始先结算金钱龟、小小龟、倍数龟；掷出后王冠改本手结果；从左到右处理结算；最后结算母猪与光牙。同类重复器建议令对应阶段效果总共执行两遍。二重唱建议覆盖本体及首领、领队的宿主结算壳效果。 | 同时有二重唱和附魔师，喂养者喂两遍，母猪喂两遍；基础得分、过关奖励、扣命各记一次。领队的宿主可生两只基础龟，新龟自身没有结算效果。 |
| 饲料 | 基础点数 +1 表示长期六面各 +1。肉猪收到 1 份记为 2 份；另一个贪吃猪只跟 1 份，跟喂不再广播。批发商卖出只提升之后的新饲料。转移猪继承原份数和实际点值，一笔喂给随机剩余骰，接收者仍可触发受喂效果。 | 初始六面全 1 的肉猪收到第一份普通饲料后六面全 3；卖出批发商后再收到一份，六面全 7。 |
| 吸附的附加规则 | 按 D7 转移六面。龟建议另将吸附前的实际可售金额加给宿主。倍数龟建议把宿主全部并列最高面翻倍一次。基础龟建议兼有普通货架和领队生成两个来源，生成时直接吸到宿主。 | 吸附一只基础龟，宿主六面各 +1、卖价 +1；吞噬一只六面相同的祭品只获得相同的点数。 |
| 首领龟计壳与归分 | 按 D10，每只壳给它所在的外部骰 +1 分。建议领队生成的基础龟也计入；已算分的外部骰补记壳分，后位骰保留待记贡献，同一笔加分只登记一次。 | 其它两颗骰分别附 2 只和 1 只，分别获得 +2 和 +1，首领宿主自身本次不领这 3 分。 |
| 市场与恶魔 | 小鬼按 D11 整局强化货架。吸血按本次市场成功购买的骰数 +2，建议含后刷货架，货架临时层仅在市场取值，吞噬锁定当时有效六面。深渊每次进店建议合计抽 1–3 个祭品、优先占骰子格，多颗不重复占格；普通付费刷新不补祭品。 | 首次有一颗小鬼进店，祭品底面 1、常驻层 +1。买过一颗骰且有吸血后吞噬，读取六个 4；直接买入普通商品不会把吸血层带到下一关。 |
| 祭品与抢吃次序 | 蝠魔指挥其它己方恶魔各吃 1 个剩余商品，建议先吃祭品，其余按货架顺序；始祖魔从所有剩余骰商品（含祭品）等概率抽 1 颗由自己吃。主动买祭品建议交给袋序首颗恶魔，算一次买骰及一次吞噬；无恶魔时不可奉献，满袋仍可奉献。 | 先锁定被吃商品、受益者与当时的有效六面，再广播事件。两个恶魔只剩一份食物时，仅成功一次、吞噬骰只发一次金。 |
| 海盗交易 | 海盗出售建议返还购入实付，加吸附壳卖价。税务按 D8 逐件减 1，建议最低 0、先税务后半价并向下取整。头领每回合可半价买一只，原型建议在其对应的市场给一笔额度，店中买入头领从之后一单可用，多头领共享一次，刷新不重发。哨兵沿用刷新基础费曲线；人口海盗建议按持有实例跨市场累计主动售出。 | 标价 7 的海盗经一颗税务为 6，首次半价付 3、直接卖回 3。净刷新费为 -1 时获得 1 金，触发一次财宝海盗。 |
| 抢劫的结算细节 | 按 D6，已结算左邻也须校正。建议以王冠调整后的本手骰点为可夺值，已被抢过的点不能再拿；只转移骰点。邻骰独立发动的金币、喂养等效果保留。邻骰本手附加单骰分建议随其贡献归零。正数余量从第一面起分，负数按绝对值均分后还原符号。 | 左邻投 4、右邻投 5，海盗共拿 9，六面分别长 2/2/2/1/1/1，邻骰本手计零。若左邻另有壳加 2 分，这 2 分不并入劫得的 9 点。 |
| 光牙与王冠 | 光牙按四个主体家族去重，每个家族使全袋所有实体各面 +2。王冠建议从已投实体中随机选最多两个不同目标，可选自身，改为各自最大面。 | 两颗同族猪、一颗恶魔、一颗光牙共两个家族，四颗骰各面 +4。只剩一颗可选骰时王冠只调整它。 |

定价、分章权重和高阶保底需在一轮实玩后校准。旧表的价格和权重可用于搭建对照组，新增骰未给出的数值留空。重点观察倍数龟的增长速度、抢劫对本手总分与下手六面的影响、负费刷新触发财宝海盗的频率，以及三类重触发的叠加。
