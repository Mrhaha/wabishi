# F024 验收用例

2026-11-23 已接入 Unity 运行时。已执行的名单、市场、回合与保存回归，以及固定种子试玩结果见 [运行记录](../../../QA/20261123_f024_runtime.md)。下列逐骰场景作为持续验收清单；价格与整局平衡仍待人工实玩。骰子身份和退役映射见同目录 `ROSTER.md`。

## 测试准备

2026-11-23 已完成设计资料核对。新旧名册与工作区类型表、市场表的类型集合一致；导出后重开调整表，逐项核对到沿用 4、重制 20、新增 6、废弃 30、系统专用 2。下列 30 个逐骰用例均有对应名册项，六项用户补充裁定已同步。以下运行结果须等代码接入后记录。

固定骰袋顺序、实例、六面、钱包、货架和随机种子。每次只放表中点名的效果骰，陪测用无效果的基础骰。记录动作前后每颗骰的六面、锁定结果、本次计分、卖价、货架、钱包及规则日志。使用同种子重跑并切换演出速度，逐项比对。每实际投一手计一个回合。失败扣命后续投的新一手要再次触发回合效果。另测从续投检查点恢复到准备界面，仅在真正续投时触发新一手。若正文标「待确认」，待策划确定口径后再签收该项。

## 五组骰子逐项验收

### 猪

| 骰子 | 布置与操作 | 观察结果 |
|---|---|---|
| 喂养者 | 两侧放无饲料的普通骰，一次发动，再将喂养者移到边缘重做 | 中间时左右各得一份，默认各面 +1。边缘时只影响存在的邻骰。 |
| 肉猪 | 与普通骰各吃一份相同饲料，随后各再吃一份 | 每次肉猪实际获两份，累计受益始终是对照的两倍。日志可分辨一次投喂与实际获得的份数。 |
| 转移猪 | 带三份饲料，袋里只有一个剩余对象。卖出，再以多个对象重做 | 唯一对象收到转移。多个对象时只命中其中一个、卖出的猪离袋。以不同时期取得的饲料另测转移结算，按确认的质量口径核对。 |
| 母猪 | 放母猪及两颗无饲料骰，完成一次回合 | 到回合结束时两颗各获一份，母猪自身份数不变。记录本手锁定点与下回合六面。 |
| 贪吃猪 | 分别只喂普通骰、另一只猪、另一只肉猪，然后放入第二枚贪吃猪复测 | 喂普通骰不响应。每次另一只猪获得饲料时，本骰加一份。复测两只监听者时按防递归规则收束，并可查到每份来源。 |
| 批发商 | 同一局先喂一次，买入批发商再喂一次，卖出后再喂一次 | 买入不触发升级，卖出才使一份饲料的加值 +1。分别记录老饲料与卖后新饲料，按确认的追溯规则核对。 |

### 龟

将六面为 1/2/3/4/5/6、可售 4 金的龟吸附到六面为 1/1/1/1/1/1、可售 3 金的合法宿主上。预期六面对位相加得到 2/3/4/5/6/7，宿主可售 7 金，龟离袋一次，壳效果保留。接着吸附一只基础龟，宿主变为 3/4/5/6/7/8、可售 8 金。另测没有合法宿主时，双方六面、卖价和骰袋占位都不变。

| 骰子 | 布置与操作 | 观察结果 |
|---|---|---|
| 金钱龟 | 吸附后在同一关投两手，第一手失败扣命并续投。记录金钱龟的收入来源 | 第一手获得 1 金，续投的第二手再获得 1 金。两手合计 2 金，其他钱包收支单列。 |
| 小小龟 | 完成吸附后拍下宿主六面，经过一个回合 | 在吸附转移之外，宿主六个面各再 +1。 |
| 倍数龟 | 准备吸附后最高面唯一且为 6 的宿主，经过一个回合 | 该最大面变为 12。另设多个最大面测试并列规则，核对临时点和永久点的显示。 |
| 首领龟 | 从左到右放带两只基础龟的骰、首领龟宿主、带一只基础龟的骰、无壳骰。固定四骰各自投 4 点，无其他加分。宿主结算时左边第一颗已完成计分 | 每个外部壳为所属骰增加 1 点本手分。左骰已提交的贡献从 4 补至 6，右骰结算为 5，首领宿主和无壳骰各为 4。合计 19，四颗的锁定骰点与长期六面不受这项加分影响。 |
| 领队龟 | 一枚领队龟已吸附，宿主结算一次 | 只给该宿主增加一枚基础龟。分别检查壳数、六面和卖价的差值。新壳不会再生领队龟或重复扣占骰袋格。 |
| 基础龟 | 取得一枚无强化的基础龟并检查卖价，再让其吸附 | 初始六面均为 1、卖价为 1。以实际龟吸附时，宿主六面各 +1、卖价 +1。与开局基础骰的身份独立。 |

### 恶魔

用六面为 1/2/3/4/5/6、卖价 4 金的无壳市场骰作来源。吞噬者六面为 1/1/1/1/1/1、原卖价 3 金。吞噬后六面对位相加得到 2/3/4/5/6/7，吞噬者仍可售 3 金。该格清空一次，同一来源不能再买入或被第二颗骰吞噬。

| 骰子 | 布置与操作 | 观察结果 |
|---|---|---|
| 小鬼骰子 | 同一局持有一枚小鬼，连续进两次市场，两店各刷新一次。货架固定使用无其他强化的六面全 1 商品，袋中留一枚对照骰 | 首次进店时架上六面均为 2，同店刷新出的新商品仍均为 2。第二次进店均为 3，再刷新仍为 3。两个市场中袋内对照骰的六面始终保持原值。 |
| 蝠魔骰子 | 带蝠魔及两枚其他恶魔离店，货架有两颗不同来源。再用一颗和零颗来源重做 | 可用时，每枚其他恶魔各吞一颗不同来源。仅一颗时只能成功一次，没有来源时均跳过。 |
| 吸血骰子 | 同市场内连续成功买两颗骰，观察未动的对照货架，随后离店 | 对照六面依次 +2、累计 +4。离店解除本市场临时值，下一市场从其应有基线开始。分别核对买入与吞噬时的临时值去向。 |
| 深渊骰子 | 固定能抽到 1、2、3 的三组种子分别进店，另用无空余货位或没有合法吞噬者的场景复测 | 每次生成的目标数量落在 1～3，按已确定货架规则落位。祭品无强化时六个 1，能接受市场强化且只供恶魔吞噬。空位和无目标情况按策划选定处理。 |
| 吞噬骰子 | 制造两次成功吞噬和一次空目标尝试 | 钱包仅因两次成功事件各 +1。普通买入、吸附或尝试失败各自不产吞噬金币。 |
| 始祖魔骰子 | 在场时依次购买普通骰、恶魔骰，留两颗货架骰作可选目标 | 仅成功购买恶魔触发一次随机吞噬，来源属于当时仍可吞噬的货架。架空时交易仍能收束。 |

### 海盗

先以同一颗无其他增减项的海盗核对买价和卖价。再在税务骰、半价、龟壳同时存在时记录实付、显示卖价与实际收入，按选定的海盗价格口径逐项对账。

| 骰子 | 布置与操作 | 观察结果 |
|---|---|---|
| 哨兵海盗 | 使本次基础刷新费为 1，分别持有零、一、两枚哨兵并手动刷新 | 分别扣 1、扣 0、返 1。正、零、负三种报价与实际收支吻合。 |
| 抢劫海盗 | 左右各放一颗投出 6 点的骰，左邻已计入本手分数，并已触发一次喂养或金币。结算抢劫一次，再以只有一个邻居、两邻点数不整除六及连续抢劫复测 | 海盗拿走两邻本手投出的 12 点，长期六面各 +2，本次抢劫共得 3 金。两邻本手骰点都计 0，已计入的左邻骰点须校正，邻骰长期六面及独立喂养、金币维持原值。第二次不能再从已清零的骰点取得同一笔点数。若邻骰另有独立加分，单列核对是否保留，该项不计入被抢点数。余数与负点按正式裁定核对。 |
| 财宝海盗 | 得一笔 3 金，再单独得两笔各 1 金。此期间禁用其他成长 | 一笔 3 金只选一颗骰、全部面 +1。两笔各触发一次。支出和零额交易无加值。 |
| 海贼王 | 三组独立样本均锁定投出 4 点，钱包分别为 2、3、7 金。只结算本骰一次 | 六个长期面分别各增长 0、1、2。本手锁定点及用于基础计分的点数均为 4，钱包不消耗。 |
| 海盗头领 | 按“每次入市发放一次”的建议，带一枚头领进店。先尝试失败购买和买普通骰，再买原价 4 金的海盗。刷新后再买一颗原价 4 金的海盗。下次进店重复首购 | 前两步不消耗优惠。首张合格海盗实付 2 金，同店刷新后实付 4 金，下一次入市的首张合格海盗再次实付 2 金。 |
| 人口海盗 | 同一市场手动卖出四颗骰，分开记录卖价回款和人口海盗收入 | 第 2、4 次各多 1 金，第 1、3 次无额外收入。额外收入可被财宝海盗监听。另测奇数进度跨市场的保留口径。 |

### 中立

| 骰子 | 布置与操作 | 观察结果 |
|---|---|---|
| 光牙骰子 | 一枚光牙、两枚同家族骰、另一家族一颗，完成结算 | 以现有主体家族口径计两个不同家族，结算结束时每颗骰的六面各 +4。同家族重复不新增家族数。再核对已吸附龟壳的身份。 |
| 王冠骰子 | 令所有候选骰自然点小于自身最大值，再触发王冠。复用种子运行两次 | 投出后有两颗不同实例调至各自最大，其他自然点正常，结算读取调整后的点。少于两颗候选时按确认的不足规则处理。 |
| 附魔师骰子 | 以母猪作为唯一回合结束效果，场上另有一枚附魔师 | 回合结束效果对同一目标执行两次。主结算计分独立记账，附魔师自身不引发无限重放。 |
| 税务骰子 | 三格各放原价为 4 金的骰子，带一枚税务骰进店，购买其中一格 | 三颗骰子逐件各减 1 金，报价依次为 3、3、3，合计 9 金。首件实付 3 金，另两件仍各报 3 金。 |
| 回溯骰子 | 一枚回溯和一个确定归入回合开始的效果，记录各阶段根事件 | 开始效果执行两次。若采用金钱龟在回合开始给钱的建议，一枚金钱壳在此场景合计 +2 金。投掷、计分与回合结束各自按原次数执行。 |
| 二重唱骰子 | 一枚二重唱与一次喂养者结算，另放一个回合结束效果 | 喂养者的结算效果执行两次。用独立计数核对回合结束、基础计分和下一回合，不跨阶段复制。 |
