## 用户修正

上一版把两骰一法术示例做成了固定柜体，不能充分容纳多张法术和变化的骰子商品数，用户已明确指出该结构会限制后续功能。原图只保留材质参考，不再作为布局母版。

## 当前候选

- 左侧保持自有骰袋；右侧商品区改成上排骰子、下排法术，两类同时可见。
- 两条贯通陈列面分别承载重复商品模块，不在背景烘焙固定货格数、卡槽或购买键。
- 数量少时保留标准单品尺寸与普通柜内留白；数量超过一屏时，由该类区域翻页。页面可见数不构成玩法或配置上限。
- 购买、吞噬、抢走后保持该批原位置与页码，已售空位参与稳定展示，不自动挤走其余商品。
- 标题与商品数量、分页只属于展示层；真实货架索引、同价最左、换货目标和离场规则仍由实际数据与规则确定。
- 底部保留一个整批刷新入口、我的法术袋和离开市场。

## 容量示意与候选尺寸

本轮用三颗待购骰子与三张待购法术展示扩展能力。该画面是容量示意，不代表正式市场供给已改为六件，也不将六件写成未来上限。

以 `1280×720` 为布局参考：左侧骰袋宽约 `176`，右侧商品区宽约 `1032`；骰子模块约 `176×200`、间距 `16`，一屏约五颗；法术卡约 `296×230`、间距 `16`，一屏约三张。以上是待实际字库装入复核的尺寸候选，不是冻结规格。

法术必须完整显示正文。空间不足时先降低每页可见卡数，不能持续缩字或裁掉规则。各类翻页控件只在确有超出时出现，买走一件不自动跳页，刷新后统一重建。
